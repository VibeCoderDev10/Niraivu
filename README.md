# NIRAIVU (நிறைவு)
### Drug Abuse Awareness, Prevention & Recovery Platform
**“Awareness. Prevention. Recovery.” — Towards a Drug-Free Tamil Nadu (போதையில்லா தமிழ்நாடு)**

---

## 🌟 Overview
**NIRAIVU** is a modern social-impact digital health platform engineered to support the vision of a **Drug-Free Tamil Nadu**. Built for youth, college students, parents, and educators, it bridges the gap between public health resources and real-world peer challenges with an empathetic AI guide, an interactive rehabilitation locator, and actionable refusal scenario simulations.

---

## 🚀 Key Features

### 1. 🤖 "NIRA" AI Awareness & Support Guide
- Confidential, non-judgmental conversational assistant.
- **Safety Safeguards**: Real-time triage detecting overdose or crisis symptoms with an instant high-priority emergency banner connecting directly to **108 Emergency Ambulance** and **14446 Tele-MANAS**.
- **Evidence-Based Knowledge**: Teaches the CLEAR refusal framework, coping skills, and guidance on helping struggling friends.
- Zero instructions on drug procurement or concealment.

### 2. 📍 Interactive Tamil Nadu Center Locator
- Interactive **OpenStreetMap & Leaflet** mapping with verified government hospitals and recognized de-addiction centers across Tamil Nadu.
- **"Use My Location"** GPS geolocation with real Haversine distance calculations in kilometers.
- Filter by district (*Chennai, Coimbatore, Madurai, Tiruchirappalli, Salem, Tirunelveli, Vellore, Erode, Thanjavur, Kanyakumari*).
- Direct one-tap phone dialing (`tel:`) and Google Maps directions.

### 3. 🎯 "What Would You Do?" Interactive Decision Lab
- Practical scenario simulations reflecting college hostel life, party peer pressure, and family dilemmas.
- Instant pedagogical feedback, refusal tactic breakdowns, and celebratory micro-interactions.

### 4. 📚 Substance Knowledge & Prevention Lab
- In-depth clinical breakdown of 8 substance categories: Alcohol, Tobacco/Vapes, Cannabis (Ganja), Opioids, Stimulants, Sedatives, Inhalants, and Novel Synthetics.
- Demystifying the neurobiology of dopamine hijack and brain plasticity.
- Actionable prevention playbooks tailored for **Students**, **Parents**, and **Friends**.

### 5. 🚨 24/7 Verified Emergency Helplines
- **108** — Tamil Nadu Free Emergency Medical Ambulance Service
- **14446** — National Tele-MANAS Mental Health Helpline (Toll-free 24/7, Tamil & English)
- **104** — Tamil Nadu Health Information Advisory
- **112** — National Emergency Response Support System (ERSS)
- **1933** — MANAS National Anti-Narcotics Helpline (NCB)

## 🛠️ Tech Stack
- **Frontend Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 (Deep Navy & Teal/Cyan design system)
- **Mapping**: Leaflet + OpenStreetMap
- **Icons**: Lucide React
- **Celebration**: Canvas-Confetti
- **Deployment**: Vercel ready with custom `vercel.json` SPA rewrite rules

## 💻 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/VibeCoderDev10/Niraivu.git

# Navigate into directory
cd Niraivu

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

---

## 🌐 Production Build

```bash
npm run build
```
